# Data Model — 030 Table Styles Catalog + Gallery + Theme

## TABLE_STYLE_DEFS (generated module, `src/renderer/core/generated/table-style-defs.ts`)

```ts
export const TABLE_STYLE_DEFS: Record<string, {
  name: string;       // Word display name, e.g. "Grid Table 4 - Accent 1" family naming per catalog
  basedOn: string | null;   // usually "TableNormal" (must exist — it ships in every doc's defaults)
  section: 'plain' | 'grid' | 'list';   // gallery section, derived from the name family
  xml: string;        // verbatim <w:style w:type="table" ...>...</w:style> (rsid stripped)
}>;
```

- Source of truth: `parity/oracle/table_style_defs.json` (113 entries, locked-build captures).
- Generated by `scripts/gen-table-style-defs.js`; AUTO-GENERATED banner; never hand-edited.
- Section rule: name starts with "Plain Table"/"Table Grid" → plain; "Grid Table" → grid;
  "List Table" → list.

## Materialization state (runtime, per document)

- `converter.convertedXml['word/styles.xml']` — xml-js tree; a catalog def is spliced in AT MOST
  once, and only if no `<w:style w:styleId=id>` already exists (`existsOnDoc` guard = import
  precedence).
- `converter.translatedLinkedStyles.styles[id]` — the fork's translated entry (required by
  `resolveTableStyleVisuals` for in-app paint); registered together with the splice.
- `STYLE_NAME_TO_ID` / `STYLE_ID_TO_NAME` — display-name mapping registered on materialize.

## Preview snapshot (transient, bridge-local)

```ts
{ state: EditorState,           // pre-preview editor state (restore via editor.setState ONLY)
  documentModified: boolean,    // converter dirty flags to restore
  activeStyleId: string | null } // for the hop contract
```

- Never persisted; cleared on leave/commit/input-cancel/tab-teardown.
- Preview transactions carry `addToHistory:false` — undo stack length is an invariant.

## Theme palette (reference only — no new runtime entity)

- Doc theme: `converter.themeColors` (parsed from the doc's theme1.xml — already doc-wins).
- The GT4A1 fallback def's literal hexes (fork data) must equal the locked-build capture's
  (accent1 #156082 derivations) — asserted by a pm test, not a runtime structure.

## Gallery tile (chrome DOM, transient)

- `.tblstyle-cell[data-style-id]` → contains `.tblstyle-thumb` (4×5 `.tst-row`/`.tst-cell`
  mini-table); `.active` marks `tableInfo().styleId`; hover → preview enter; click → apply.
- Tile colors: header hue = accent index parsed from the display name → `WC._themeAccents`
  (fallback: THEME_COLORS map); banding tint = rgba(0,0,0,.07); plain family = no header shade.
