# Task 11 — Make 3 nested triangles with the same center, alternating two colors.

**Difficulty:** Easy  •  **Time horizon:** 8 min

## Thorough description

Draw 3 triangles of decreasing size (use the Polygon tool with 3 sides), all centered together, alternating two colors. The largest at the back, smallest at the front. Use alignment buttons to share the same center x.

## Simplified prompt

> Make 3 nested triangles with the same center, alternating two colors.

## Step-by-step

1. Click Polygon tool. 2. Drag the largest triangle, pick color A. 3. Right-click then Duplicate, scrub size smaller, pick color B. 4. Duplicate again, scrub even smaller, pick color A. 5. Marquee all 3 then click Align horizontal centers.
