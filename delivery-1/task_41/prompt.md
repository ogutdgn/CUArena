# Task 41 — Build a search bar: rounded rectangle + magnifying-glass icon + 2 dots.

**Difficulty:** Medium  •  **Time horizon:** 18 min

## Thorough description

Build a search bar: a rounded rectangle bar + a magnifying glass icon (small circle with stroke + thin diagonal line at the bottom-right of the circle for the handle) + 2 small dot placeholders inside the bar.

## Simplified prompt

> Build a search bar: rounded rectangle + magnifying-glass icon + 2 dots.

## Step-by-step

1. Click Rectangle tool, drag the bar, scrub corner radius to 24. 2. Click Ellipse tool, draw the magnifier ring (no fill, 2px stroke). 3. Click Line tool, draw the diagonal handle at the bottom-right of the ring. 4. Click Ellipse tool, draw 2 small dots inside the bar.
