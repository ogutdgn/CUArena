# Task 7 — Make a layered gray mountain range using two overlapping pen-tool paths in different shades.

**Difficulty:** Easy  •  **Time horizon:** 12 min

## Thorough description

Create a 1000x400 frame. Use the Pen tool to draw a mountain silhouette: click anchors at ground level, peak, valley, peak, ground level, then close the path. Apply dark gray fill. Draw a second smaller mountain in front in a slightly lighter gray.

## Simplified prompt

> Make a layered gray mountain range using two overlapping pen-tool paths in different shades.

## Step-by-step

1. Click Frame tool, drag a 1000x400 frame. 2. Click Pen tool. 3. Click ground-left, then peak, valley, peak, ground-right. 4. Click first anchor to close. 5. Press Escape. 6. Pick dark gray fill. 7. Click Pen tool again. 8. Draw second smaller mountain. 9. Press Escape. 10. Pick lighter gray fill.
