# Task 22 — Draw 4 same-size pill rectangles in a horizontal row with different pastel fills.

**Difficulty:** Easy  •  **Time horizon:** 10 min

## Thorough description

Draw 4 same-size rounded rectangles (corner radius 999) placed side-by-side in a horizontal row, each filled a different pastel color, all sharing the same y-baseline.

## Simplified prompt

> Draw 4 same-size pill rectangles in a horizontal row with different pastel fills.

## Step-by-step

1. Click Rectangle tool. 2. Drag the first pill, scrub corner radius to 999. 3. Pick a pastel color. 4. Right-click then Duplicate, drag right, recolor. 5. Repeat for 4 total. 6. Marquee all. 7. Click Align top.
