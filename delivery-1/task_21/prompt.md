# Task 21 — Stack 3 same-size rectangles vertically, different colors, aligned on x.

**Difficulty:** Easy  •  **Time horizon:** 10 min

## Thorough description

Draw 3 same-size rectangles stacked vertically, each a different fill color, all sharing the same x-center with consistent gap between them.

## Simplified prompt

> Stack 3 same-size rectangles vertically, different colors, aligned on x.

## Step-by-step

1. Click Rectangle tool. 2. Drag the first rectangle. 3. Right-click then Duplicate, drag below. 4. Drag the third rectangle below the second. 5. Pick a different fill for each. 6. Marquee all 3. 7. Click Align horizontal centers.
