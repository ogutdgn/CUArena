# Task 2 — Stack 5 horizontal rectangle bands in sunset colors (purple, pink, orange, yellow, pale yellow).

**Difficulty:** Easy  •  **Time horizon:** 12 min

## Thorough description

Create a frame and inside it stack 5 horizontal rectangles top-to-bottom in sunset colors: deep purple, pink, orange, yellow, pale yellow. Each rectangle is the same width and a similar height; arrange them flush against each other to look like a sunset gradient simulated with solid bands.

## Simplified prompt

> Stack 5 horizontal rectangle bands in sunset colors (purple, pink, orange, yellow, pale yellow).

## Step-by-step

1. Click Frame tool, drag a frame. 2. Click Rectangle tool. 3. Drag first band, pick purple. 4. Drag second band below, pick pink. 5. Drag third band, pick orange. 6. Drag fourth band, pick yellow. 7. Drag fifth band, pick pale yellow. 8. Marquee all, click Align horizontal centers.
