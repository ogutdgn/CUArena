# references/ — inspire, never dictate

Read for patterns and lessons; never copied as templates, never trusted as facts.

- `word-crawler/` — a hand-built UIA crawler for MS Word (the reference method: dump-tree,
  press-observe-classify, seen-set recursion, journal-rebuild). The clearest model of how an
  agent should drive an app.
- `docs-harvester/` — a help-center docs extractor (markdown + reference tree).
- `legacy/` — the code WE built in Plan A + B1 before the architecture pivot (pipeline/, tools/,
  tests/). Proven, tested, full of hard-won lessons (locale titles, OneDrive AutoSave, broker
  pids, PrintWindow, control-type casing). It is the seed material for `toolbox/` tool knowledge
  and for the agent's own per-app tools — not the live system anymore.
- `history/` — old plans and validation reports from the pre-pivot approach, kept as record.
