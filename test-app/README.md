# Figma Keyboard Shortcuts

Complete reference of Figma Design keyboard shortcuts. Mirrors Figma's in-app shortcut panel (`Ctrl+Shift+?` on Mac).

## Essential

| Action | Mac | Windows |
|---|---|---|
| Show/hide UI | `⌘\` | `Ctrl+\` |
| Pick color (eyedropper) | `I` | `I` |
| Search menu / quick actions | `⌘/` or `⌘P` | `Ctrl+/` or `Ctrl+P` |
| Toggle multiplayer cursors | `⌥⌘\` | `Ctrl+Alt+\` |
| Show/hide rulers | `⇧R` | `Shift+R` |
| Show/hide layout grids | `Ctrl+G` | `Ctrl+Shift+4` |
| Show/hide outlines | `⌘Y` | `Ctrl+Shift+3` |
| Pixel preview | `⌘⇧P` | `Ctrl+Shift+P` |
| Pixel grid (≥ 1600% zoom) | `⌘⇧'` | `Ctrl+Shift+'` |

## Legend

- `⌘` Command (Mac)

- `⌥` Option / Alt
