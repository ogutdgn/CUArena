## How to read this index

- **Slug** is the canonical reference (matches the directory name under `helper/figma_docs/articles/Figma Design/`).
- **Title** is the article's title field from `metadata.json`.
- **img** = image_count (visual reference value).
- **links** = internal_link_count (how richly cross-referenced — high values usually = umbrella / hub article).
- Read this index when planning what to read; read the article's `content.md` for the actual material.

For per-feature behavior specs derived from these articles, see `helper/extracted/features/<category>/<feature>.md`.
For dependency-graph clustering and tier ordering, see `dependency-clusters.md`.
For panel-state matrices and UI3 chrome layouts, see `panel-states.md`, `ui-map.md`.
For high-level flow walkthroughs, see `workflows.md`.
For per-feature inputs/outputs/edge cases, see `feature-inventory.md` (broad/shallow) plus the deep specs under `extracted/features/`.
