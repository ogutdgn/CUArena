# 2026-05-26 — W4 core: generic JSDialog → native QML

## What shipped

**Phase W4 core**: LOK dialogs render as native, in-app QML and round-trip back
to the engine. One generic renderer, not per-dialog QML (DECISIONS D11).

- **Research-first** (probes in `tests/`):
  - `dialog_probe.cpp` — dumps full `LOK_CALLBACK_JSDIALOG` widget trees
    (`/tmp/jsdlg_<Cmd>.json`) to design against the real schema.
  - `dialog_audit.cpp` — per-command surface classifier → `W4_DIALOG_COVERAGE.md`.
  - `dialog_roundtrip.cpp` — proves `sendDialogEvent` closes a modal dialog.
- **`LokEngine`** captures JSDIALOG (46) + WINDOW callbacks → `jsDialog` /
  `windowEvent` signals; exposes `Q_INVOKABLE sendDialogEvent(windowId, json)`.
- **`DialogWidget.qml`** — recursive widget-tree renderer (container/grid/
  fixedtext/edit/checkbox/radiobutton/listbox/combobox/spinfield/pushbutton/
  tabcontrol). Recurses via Loader-by-URL (QML forbids self-instantiation).
- **`DialogHost.qml`** — in-app modal overlay: parses the full tree + incremental
  `update`/`action`/`close` messages, renders the root, routes interactions to
  `sendDialogEvent`, dismisses on close.
- Verified headless: **Word Count** (3-column grid, real counts) and **Page
  Style** (10-tab tabcontrol with labels: General/Page/Area/…/Text Grid) render
  cleanly; round-trip cancel acks `action:"close"`.

## Confirmed protocol (W4_DIALOG_COVERAGE.md)

- windowId = tree root **`lokWindowId`** (the string `id` may be a name).
- event = `{"id":<ctrl>,"type":<widget>,"cmd":<action>,"data":<v>}`; action
  buttons = `responsebutton`/`click`; engine acks `action:"close"`.

JSDIALOG (native-renderable, no engine patch): Page, Font, Paragraph, Search,

## Snags + fixes

- **Relative engine path crash** — `lok_cpp_init` needs an *absolute*
  `instdir/program` (else `theDefaultProvider` UNO bootstrap abort). Documented
  in ENGINE_BUILD.md; probes `cd … && pwd` the path.
- **QML "instantiated recursively"** — switched recursive children to
  Loader-by-URL.
- **windowId confusion** — runtime root `id` is a *name* (`"WordCountDialog"`)
  and ids are per-session sequential; the numeric `lokWindowId` is the one
  `sendDialogEvent` wants. Modeless dialogs (Word Count) close silently, so the
  host also dismisses optimistically on ok/cancel/close.
- **Blank tab labels** — tabcontrol carries a separate `tabs:[{text,id}]` array
  (parallel to the page `children`); wired it + `selected`→initial index.
