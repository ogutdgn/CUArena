# 2026-05-26 — W5: raw/semantic/outcome logger (figma-parity)

## What shipped

**Phase W5**: the contract-conformant logger, sourced entirely from our own
seams (Boundary A / DECISIONS D7) — no engine instrumentation.

- **`src/logging/SessionLogger.{h,cpp}`** — session dir + three JSONL streams,
  contract base fields, sessionId (UUID), counters, env
  (`WRITER_LOG_DIR` / `WRITER_LOG_DISABLE`).
- **Wired through `LokEngine`:**
  - raw[] ← `postKey` (`key`), `typeText` (`text`), `postMouse` (`mouse`).
  - semantic[] ← `postUno`: `.uno:*` → RL name via `resources/uno-names.json`
    (1520 mappings, `tools/gen_uno_names.py` from the command catalog) + `args`
    + `rawEventIdRange` (raw events since the previous semantic).
  - outcome{} ← 1 s `QTimer`: `summary.semanticEventCount` + `wordCount` /
    `charCount` / `page` (parsed from STATE_CHANGED `StateWordCount` /
    `StatePageNumber`); `document` = {modified, pageStyle, formatAtCursor
    (curated bold/italic/font/align/style), cursor, size}. STATE_CHANGED also
    feeds `m_formatAtCursor`; cursor from `INVALIDATE_VISIBLE_CURSOR`.
- **`tools/consolidate_log.py`** — merges a session dir into the single
  figma-shaped `session.json` (`{schemaVersion, sessionId, exportedAt, raw[],
  semantic[], outcome{}}`); `--latest` picks the newest session.

## Verification (headless)

`WRITER_LOG_DIR=/tmp/wlog` + demo text `"Hello logger world."` +
`.uno:Bold,.uno:CenterPara`:
- raw-1 = text event (all base fields); sem-1/sem-2 = bold/italic|centerpara
  with `rawEventIdRange:["raw-1","raw-1"]` + args; outcome
  `summary={semanticEventCount:2, wordCount:3, charCount:19, page:"Page 1 of 1"}`,
  `formatAtCursor={Bold:true, CenterPara:true, ...}`.
- `consolidate_log.py` → valid `session.json`.
- `WRITER_LOG_DISABLE=1` → no session created. `render_test` regression green.
