# Task 42 — Build a yellow-gold bell icon + small clapper + red badge.

**Difficulty:** Medium  •  **Time horizon:** 18 min

## Thorough description

Build a notification bell: a pen-drawn bell silhouette (yellow-gold fill) + a small clapper circle below + a red badge circle in the upper-right corner with a white stroke.

## Simplified prompt

> Build a yellow-gold bell icon + small clapper + red badge.

## Step-by-step

1. Click Pen tool, draw the bell silhouette. 2. Press Escape, pick yellow-gold fill. 3. Click Ellipse tool, draw the clapper circle below. 4. Click Ellipse tool, draw the red badge circle on the upper-right. 5. Add 2px white stroke to the badge.
