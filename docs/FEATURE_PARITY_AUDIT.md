# ms-word-clone vs. real Microsoft Word — Feature Parity Audit

Generated by tracing every ribbon control through `ribbon-data.js` → `commands.js` (`H.<cmd>`) → `src/renderer/bridge/*.ts`, then adversarially verifying each "works" claim against the actual code. **Status reflects what the clone ACTUALLY does, not what the docs claim.**

## Executive summary

Across **228** audited controls:

| Status | Meaning | Count | Share |
|---|---|---:|---:|
| ✅ full | Faithful parity with Word | 70 | 30.7% |
| 🟡 partial | Real but missing options/fidelity | 116 | 50.9% |
| 🟠 wrong | Acts, but output diverges from Word | 6 | 2.6% |
| ❌ stub | Toast / dialog-only / no doc change | 34 | 14.9% |
| ⬜ missing | No handler | 2 | 0.9% |

**Headline:** 186/228 (81.6%) controls do something real (full+partial); 70 (30.7%) reach faithful parity.
